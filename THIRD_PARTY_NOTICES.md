# Separately distributed dependencies

This repository contains example source code, a public brain design, and a
Webots world. Dependencies retain their own licenses and are not relicensed
under the Artificial Brains Example Code License.

| Dependency | Distribution and license information |
| --- | --- |
| Artificial Brains SDK | Installed from `requirements.txt`; see the [SDK repository](https://github.com/artificial-brains-inc/artificial_brains). |
| Webots | Installed separately by the user; see [Cyberbotics Webots](https://github.com/cyberbotics/webots). |
| Python and Python packages | Use the license notices supplied with each installed distribution. |

The Webots application, SDK implementation, device firmware and compiled brain
packages are not included in this repository. No `sensor_firmware/` directory
is included; the license's reference to such a directory applies only where it
is distributed.
